# Репет

Небольшое адаптивное приложение для управления расписанием репетитора.

## Запуск

Установите Node.js 18+ (в текущей среде Node.js не установлен) и запустите:

```bash
npm start
```

Откройте `http://localhost:3000`. Сервер автоматически создаёт `data/database.json` и хранит в нём пользователей, учеников и уроки.

## Возможности

- вход по номеру телефона и паролю (демо-режим);
- недельный календарь с уроками на 45 минут, 1 час или 2 часа;
- добавление и редактирование учеников со ставкой и заметками;
- отметки о проведении урока и получении оплаты;
- статистика доходов и список последних уроков;
- экспорт расписания в `.ics` для календаря iPhone и компьютера.

Данные сохраняются на сервере в `data/database.json`, а не в `localStorage`.
